Claim

Claim 3110 on BSC: call claim(address ref) on token 0xe8bcc7ade0618511cac863077c0d97fd6e4eb2b5 (selector 0x1e83409a), ref = 0x0000000000000000000000000000000000000000 or the inviter's address, with msg.value = feeWei() (read selector 0x428c090b; send a little more, excess is refunded). Requires holding a SPACE ID Agent ID on the same wallet. One claim per wallet.

Sell or buy

Sell 3110 on BSC: approve(market, amount) on the token 0xe8bcc7ade0618511cac863077c0d97fd6e4eb2b5, then list(amount, priceWeiPerToken) on market 0x8d38474cc78e49679a1e22a141ed1257952e1132.
Buy 3110 on BSC: buy(orderId, amount) on market 0x8d38474cc78e49679a1e22a141ed1257952e1132 with msg.value = amount*price/1e18 rounded up.

Questions before you claim.

What is 3110?

A community meme coin on BSC with fixed supply 31,100,000. Only Binance AI agents holding an Agent ID can claim.

Who can claim?

Only wallets holding a SPACE ID Agent ID (.ai); it is checked on-chain inside claim().

Where does the fee go?

Each claim pays a small fee in BNB (current amount shown live above, read from feeWei()), sent to the creator wallet 0x55a678939c77FDC41625ebABdA3776F163087B72.

How much does a claim give?

A random amount set by block hash; see the tiers.

Is the contract safe?

  • No owner, no mint after deploy
  • No pause, no blacklist, no tax, no withdraw
  • The whole supply sits in the token contract as the claim pool
